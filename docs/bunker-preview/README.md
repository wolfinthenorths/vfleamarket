# Предварительный макет: подземный Блошиный рынок

Этот каталог содержит отдельное предложение по оформлению. Рабочие файлы приложения в `public/` не меняются. Развертывание из этой ветки не требуется.

## Источники изображений

- Фон: настоящий игровой скриншот **Rivet City Market**, **Fallout 3**, Bethesda Game Studios. Источник: https://fallout.wiki/wiki/Rivet_City_Market ; файл: https://images.fallout.wiki/e/e9/Rivet_City_Market.jpg . © Bethesda Softworks/ZeniMax.
- Вывески магазинов: материалы, предоставленные владельцем проекта в Google Drive. В макете главной используются статичные кадры существующих GIF; исходные GIF сохраняются для приложения.
- Нюка-Кола: новая предоставленная GIF, Google Drive ID `13gr9vmwGNsIaTpkrkvzWKzSMxhPf7Ubz`, 700×350, 10 кадров, 1 222 751 байт.

Генерация изображений не используется. Затемнение игрового скриншота, рамки, типографика и элементы интерфейса выполнены обычной версткой и композицией.

## Просмотр

`index.html` — автономный макет с двумя состояниями: знакомство и рынок. Он не обращается к кассе, не меняет привязки и не списывает валюту. Выбор имени здесь показывает только поведение интерфейса. `preview.jpg` — приблизительная композиция версии для ПК и первого экрана телефона; это макет, не скриншот работающего приложения.

Бункерное оформление ожидает выбора владельца проекта. В рабочем магазине уже включены сверка Telegram username при первой привязке и дальнейшая проверка постоянного Telegram ID; согласованные фразы, первый экран и GIF Нюка-Колы также опубликованы. `current-pc.jpg` показывает рабочий сайт после этих правок, без переноса нового фона. Для Анаксы username не предоставлен.
